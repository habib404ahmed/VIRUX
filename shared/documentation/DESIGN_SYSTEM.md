# VIRUX — Cross-Platform Design System Specifications

> **Brand Personality:** Futuristic · Premium · Minimal · Professional · Modern Technology

---

## 1. Palette

| Token | Hex | Role | Usage |
|---|---|---|---|
| `background` | `#090D18` | Primary Base | Deep space dark canvas for both Web & Android |
| `secondaryBackground` | `#111827` | Secondary Base | Sidebars, headers, elevation backgrounds |
| `cardBackground` | `#172033` | Card Surface | Primary card background across Web & Android |
| `surface` | `#111827` | Elevation 1 | Sheets, bottom nav, elevated panels |
| `surfaceVariant`| `#1A2235` | Elevation 2 | Active cards, input backgrounds, modal headers |
| `primary` | `#6366F1` | Brand Accent | Primary actions, branding, key CTAs |
| `primaryDark` | `#4F46E5` | Active State | Pressed states, active nav indicators |
| `accent` | `#06B6D4` | High Tech Accent | Status beacons, highlights, data indicators |
| `textPrimary` | `#F8FAFC` | Primary Typography | Headers, primary titles, emphasized body |
| `textSecondary`| `#94A3B8` | Secondary Typography| Descriptions, subtext, captions, placeholders |
| `border` | `#1E2939` | Dividers & Borders | Subtle borders separating cards and views |

---

## 2. Status Indicators

- **Online / Active:** `#22C55E`
- **Warning / Syncing:** `#F59E0B`
- **Error / Disconnected:** `#EF4444`
- **Info / Transfer:** `#3B82F6`

---

## 3. Typography Scale

- **Display / Hero:** 48px - 57px, Bold, tracking: 0.1em - 0.5em (Uppercase for VIRUX)
- **Headline:** 24px - 32px, SemiBold
- **Title / Subheader:** 16px - 22px, Medium
- **Body:** 14px - 16px, Regular, line-height: 1.5
- **Caption / Badge:** 11px - 12px, Medium, tracking: 0.05em

---

## 4. Radii & Spacing

- Base Grid: 4px increments (4px, 8px, 16px, 24px, 32px, 48px)
- Radii:
  - Small elements / tags: `4px` - `8px`
  - Cards & modals: `12px` - `16px`
  - Pills & status chips: `9999px` (Full rounded)
